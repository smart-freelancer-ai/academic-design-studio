# 🎨 Academic Design Studio v2.0

## استوديو التصميم الأكاديمي - الإصدار الثاني

منصة احترافية لتصميم وإنشاء المحتوى البصري الأكاديمي بأعلى جودة.

## ✨ الميزات الجديدة في v2.0

### 📂 نظام التصنيف المنظم
- **🏆 الشهادات** - شهادات التقدير والمشاركة
- **🎴 البطاقات** - بطاقات الدعوة والتهنئة والباحثين
- **🥇 الأوسمة** - أوسمة التميز والإنجاز (جديد!)
- **📄 الوثائق** - ملفات بحثية ووثائق علمية (جديد!)
- **📢 الإعلانات** - إعلانات ترويجية وعروض

### 🎯 قوالب جديدة حصرية

#### 🏆 قوالب الأوسمة
1. **وسام التميز الأكاديمي**
   - تصميم فاخر للمحكمين والباحثين المتميزين
   - دعم رفع الصور الشخصية
   - إمكانية إضافة شعار الوسام مخصص
   - أرقام مرجعية فريدة

2. **وسام المحكم المتميز**
   - تكريم خاص للمحكمين المتميزين
   - نفس ميزات وسام التميز

#### 📝 قوالب الوثائق
3. **ملف قضية**
   - تصميم يحاكي ملفات التحقيق
   - مثالي للأبحاث والدراسات التحليلية
   - عرض الأدلة بالصور
   - إحصائيات مرئية
   - أسلوب فني عتيق (ورقي وخشبي)

4. **وثيقة بحثية**
   - قالب أكاديمي احترافي
   - ملخص البحث
   - معلومات الباحث مع الصورة
   - النتائج الرئيسية بالأرقام
   - الكلمات المفتاحية

### 🖌️ القوالب الموجودة مسبقاً
- شهادة المشاركة
- شهادة التقدير
- بطاقة الدعوة
- بطاقة التهنئة
- باقة المشاركة
- مقارنة الباقات
- بطاقة الباحث
- شهادة أكاديمية فاخرة
- إعلان ترويجي

## 📚 دليل الاستخدام

### 1. اختيار الوضع
- **الوضع البسيط**: للقوالب الأساسية والسريعة
- **الوضع المتقدم**: للقوالب المتقدمة مع خيارات إضافية

### 2. تفيلتر حسب التصنيف (الوضع المتقدم)
في الوضع المتقدم، يمكنك تفيلتر القوالب بسهولة:
- اضغط على أي تصنيف (شهادات، بطاقات، أوسمة، وثائق، إعلانات)
- ستظهر فقط القوالب المتعلقة بهذا التصنيف

### 3. تخصيص التصميم
- استخدم لوحة التحكم على اليسار
- عدّل النصوص والألوان والشعارات
- ارفع الصور (معتمد على القالب)

### 4. إدارة الشعارات
- أضف شعارات متعددة عبر الروابط (URLs)
- تدعم المنصة:
  - شعار منصة أريد
  - شعار الجامعة
  - شعار المحفل
  - وغيرها...

### 5. التصدير
- **PNG**: جودة عالية للطباعة
- **JPEG**: حجم ملف أقل
- **PDF**: للمستندات الرسمية

## 🛠️ التقنيات المستخدمة

- **React 18** - مكتبة واجهات المستخدم
- **Vite** - أداة البناء السريعة
- **Tailwind CSS** - إطار عمل التنسيق
- **Lucide React** - أيقونات عصرية
- **html2canvas** - تحويل إلى صور
- **Context API** - إدارة الحالة

## 🔧 التخصيص والتطوير

### إضافة قالب جديد
1. أنشئ مكون القالب في `src/components/Templates/`
2. أضفه إلى `src/data/defaults.js`
3. أضف بياناته الافتراضية
4. أضف تصنيفه في `src/data/categories.js`
5. سجّله في `TemplateRenderer.jsx`

### إضافة تصنيف جديد
عدّل ملف `src/data/categories.js` وأضف التصنيف الجديد:
```javascript
export const categories = {
  // ... التصنيفات الموجودة
  newCategory: {
    id: 'newCategory',
    name: 'اسم التصنيف',
    icon: '🎉',
    description: 'وصف التصنيف',
    templates: ['template1', 'template2']
  }
};
```
